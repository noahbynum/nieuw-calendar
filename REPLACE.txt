Nieuw Calendar 1.2.5 — replace every older copy

WordPress will not overwrite an installed plugin from
Plugins → Add New → Upload. That is why 1.2.1 and 1.2.4
ended up side by side and the calendar went blank.

Two active copies crash the site (same PHP class names).

Do this:

1. WP Admin → Plugins
2. Deactivate EVERY row named Nieuw Calendar
3. Delete EVERY row named Nieuw Calendar
   Events and settings stay in the database.
4. Plugins → Add New → Upload Plugin → this zip
5. Activate the one remaining Nieuw Calendar
6. Confirm Version 1.2.5 under the plugin name
7. Nieuw Calendar → Settings should say v1.2.5
8. Events page still uses [nieuw_calendar]
9. Purge Elementor / cache plugin / CDN cache
10. Hard-refresh the events page (Ctrl+Shift+R)

If two rows appear again, the extra one is usually
nieuw-calendar-main or nieuw-calendar-1 from a GitHub zip.
Delete that extra row.
