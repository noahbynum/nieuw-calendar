Nieuw Calendar by Nieuw Ark — month and list views, categories, color coding, and iCal export.

== Description ==

Nieuw Calendar is a focused events calendar for WordPress.

* Custom post type for events (title, description, featured image)
* Start/end date and time, optional all-day events
* Location / venue
* Hierarchical event categories with colors
* Per-event color override
* Native draft / pending / private / published visibility
* Settings for colors, border radius, and timezone
* Shortcode `[nieuw_calendar]` with month and list views
* Frontend category filtering
* iCal / .ics export at `/?nieuw_calendar_ical=1`

== Installation ==

1. Upload the `nieuw-calendar` folder to `/wp-content/plugins/`.
2. Activate the plugin through the Plugins screen.
3. Add events under **Nieuw Calendar → Events**.
4. Place `[nieuw_calendar]` on any page.
